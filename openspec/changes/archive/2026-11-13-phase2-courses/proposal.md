# Proposal

## Why

Phase 1 只完成了账号体系（注册/登录/微信绑定）与学员管理，网校还没有任何可售卖、可学习的内容载体。第二阶段需要让课程上线：学员在小程序浏览课程、试看章节、通过微信名片线下完成购买；管理后台维护课程、章节视频与课程学员名单。设计稿（Figma 333:11 / 333:10）在课程之外还出现了「资料」（文档下载）内容类型与「系统设置」页，一并纳入本阶段规范。支付暂不接入，购买闭环靠"复制销售微信号 → 线下付款 → 后台加学员"。

## What Changes

- 小程序首页改造为内容列表：品牌标题「考研资料库」+ 搜索框（课程/资料标题模糊匹配）+ 内容类型筛选器（全部/课程/资料 三 tab）+ 课程卡与资料卡混排卡片流（触底分页）；未登录可浏览
- 新增小程序课程详情页：封面区/标题/价格（或免费）/讲师·课时/简介/章节列表（试看标、锁定态、文档章节样式），底部操作栏（立即购买 / 已购买 / 免费·开始学习）；点击购买弹出微信名片弹窗（全局销售微信号 + 一键复制 + 引导文案），需登录
- 新增小程序视频播放页：原生 video 播放 + 当前章节卡（含章节简介）+ 章节列表切换；试看章节公开可播，付费课程非试看章节需登录且已购，免费课程章节登录即可播；播放地址由后端按权限签发 OSS 签名 URL（60 分钟有效）；文档章节以下载打开替代播放
- 管理后台新增课程管理模块：课程列表页（搜索 + 付费类型/状态筛选 + 状态标签 + 上架/下架/学员管理操作）、两步创建向导（Step1 基本信息：标题/封面/付费类型/价格/讲师/副标题/简介，Step2 课程内容：章节卡片管理——视频或文档/简介/试看开关/排序，保存草稿与发布课程）、课程学员页（OpenID/昵称/年级/专业/院校/加入时间 + 移出）与添加学员页（已加入灰显禁选 + 年级/专业/院校筛选 + 全选 + 批量确认添加）
- 课程上下架：下架课程从小程序列表/搜索隐藏；已购学员仍可进入详情并播放已购章节，未购者直链提示已下架
- 新增资料管理模块（设计稿补充）：后台资料 CRUD 与上下架（标题/封面/文件/格式元信息/简介）；小程序资料 tab 展示与登录后限时地址下载（Phase 2 资料一律免费）
- 新增系统设置页（设计稿补充）：承载全局销售微信号配置（取代原「课程列表页顶部配置卡片」方案）
- 新增阿里云 OSS 上传链路：管理后台浏览器经后端 STS 临时凭证直传图片/视频/文档；未配置阿里云凭证时回退本地 mock 存储（与现有微信 mock 模式同套路），播放/下载签名同步回退本地 URL
- 明确不做：支付、付费资料、资料/课程学习进度统计、免费课程自动 enroll、视频时长字段、富文本简介、「我的」页我的课程入口、阿里云 VOD、课程列表「类型」筛选（课程恒为视频）

## Capabilities

### New Capabilities
- `course-management`: 课程与章节的后台维护（两步向导 CRUD、上下架、付费类型与定价）、封面/视频/文档上传（OSS STS 直传双模式）、全局销售微信号配置（系统设置页）
- `course-enrollment`: 课程学员关系（加入时间、后台批量添加/移出、已加入灰显禁选）、小程序已购判定与下架课程的已购可见性
- `course-learning`: 小程序课程浏览与学习（首页列表搜索筛选、课程详情、章节试看与免费课程规则、签名播放地址、购买微信名片弹窗数据）
- `material-management`: 资料的后台维护与上下架、小程序资料 tab 展示与登录下载（设计稿补充能力，Phase 2 仅免费）

### Modified Capabilities

（无：Phase 1 的 user-auth / user-profile / student-management 需求层不变；本变更仅复用其用户与学员数据）

## Impact

- 后端 apps/api：新增 course 模块（courses/chapters/course_enrollments 实体与接口）、material 模块（materials 实体与接口）、upload 模块（STS 凭证/mock 回退）、settings（销售微信号）；ErrorCode 新增 16000 段（含 16007/16008 资料错误码）；packages/shared-types 同步类型与错误码
- 小程序 apps/miniapp：首页 pages/home 重写为内容列表（三 tab）；新增 pages/course-detail、pages/course-player；services 新增 course.ts、material.ts；购买弹窗组件
- 管理后台 apps/admin-web：新增 /courses、/courses/create（两步向导，step 参数）、/courses/:id/edit、/courses/:id/students、/courses/:id/students/add、/materials、/settings 路由与页面；api/course.ts、api/material.ts；侧边栏按设计稿五项导航（首页/学员管理/课程管理/资料管理/系统设置）+ 保留档案选项；品牌名「考研资料库」
- 外部依赖：阿里云 OSS（ali-oss SDK 或 STS + 浏览器直传；未配置时零外部依赖回退本地存储）
- 数据库：新增 courses、chapters、course_enrollments、materials、app_settings 五张表（TypeORM synchronize/迁移与现有模式一致）
